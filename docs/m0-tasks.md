# M0 タスク分解

M0 の完了条件（`CLAUDE.md`）を満たすまでの作業一覧。
✅ = 完了。担当: **U** = 実装者、**C** = Claude、**U/C** = 相談して決める。
`依存` 欄のタスクが終わってから着手する（並行できるものは依存なし）。

進め方の方針:
- 最初は「正しく動く最小構成」を通し、性能に関わる部分は後で足す
  - ハザードはまずスコアボードのストールだけで解決し、フォワーディングは後から入れる
  - 乗算・除算・アトミックは rv64ui が通ってから
- テストベンチ側（C の担当分）はコアと並行して進め、コアの最初の命令が確定した時点で Spike 比較まで使える状態にしておく
